# AI Event Manager Demo

This is a self-contained browser demo for an AI Event Manager serving a Charleston hospitality group.

Open `index.html` in a browser. Use the scenario buttons to show how the AI handles dietary changes, vendor timing, arrival logistics, and last-minute room changes. The message composer lets you type a custom update and see it routed to the right internal team.
